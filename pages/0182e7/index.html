whimsical 入门指南

# 简介

Whimsical (opens new window) 是一款在线协作绘图工具，适合快速创建流程图、思维导图、线框图、文档等。

# 核心功能

功能 说明
Flowcharts 流程图
Mind Maps 思维导图
Wireframes 线框图/原型图
Docs 文档

# 常用快捷键

快捷键 功能
T 文本工具 (Text)
N 节点工具 (Node)
L 连接线工具 (Line)
⌘ C 复制
⌘ V 粘贴
⌘ Shift [ 置于底层
⌘ Shift ] 置于顶层

# 工作模式

Whimsical 提供以下四种工作模式，创建文件时选择对应模式即可：

  • Flowcharts（流程图）：用节点和连接线绘制流程图、架构图等，支持多种节点形状和连线样式
  • Mind Maps（思维导图）：以树状结构发散展开想法，适合头脑风暴和知识梳理
  • Wireframes（线框图）：提供预制 UI 组件（按钮、输入框、导航栏等），用于快速绘制低保真界面原型
  • Docs（文档）：轻量级文档编辑，可嵌入流程图、思维导图等可视化内容

# Text vs Node

特性 Text Node
外观 纯文字 带边框容器
连接线 不支持 支持
用途 标题/注释 流程节点

# 使用技巧

  • 弯曲箭头：绘制连接线后，拖动线条中间的控制点调整弧度
  • 形状：点击形状工具可选择星形、圆形等预设图形
  • 层级调整：右键 → Send to back / Bring to front
  • 导出：支持导出 PNG、SVG、PDF
