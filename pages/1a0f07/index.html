启动express服务

要在 macOS 上启动本地 Express 静态服务, 您可以按照以下步骤操作:

  • 安装 Node.js: 如果您还没有安装 Node.js, 请先在您的计算机上安装 Node.js。您可以访问 Node.js 的官方网站(https://nodejs.org/)下载并安装适合 macOS 的 Node.js 版本

  • 创建 Express 项目:

    在您的项目文件夹中, 可以使用以下命令初始化一个新的 Node.js 项目, 并安装 Express 库:

mkdir my-express-app
cd my-express-app
npm init -y
npm install express

  • 创建 Express 应用: 创建一个名为 app.js 或者其他名称的文件, 并编写 Express 应用的代码。例如:
const express = require('express');
const app = express();

app.use(express.static('public'));

const PORT = 3000;
app.listen(PORT, () => {
    console.log(`Server is running on port ${PORT}`);
});

上述代码创建了一个简单的 Express 应用, 它将 public 文件夹下的静态资源托管到 / 路径上, 并监听本地的 3000 端口

  • 创建静态资源文件夹: 在您的项目根目录下创建一个名为 public 的文件夹, 并将您需要托管的静态资源文件放置在该文件夹中

  • 启动 Express 服务: 在命令行中, 进入到项目根目录, 并执行以下命令启动 Express 服务:

node app.js
1

或者使用 nodemon 工具来实时监视文件变化并重启服务器(确保已经全局安装了 nodemon):

nodemon app.js
1
  • 访问本地服务: 当 Express 服务启动后, 您可以通过浏览器访问 http://localhost:3000/ (opens new window) 来加载您的网站内容。这里的 3000 是您在 Express 应用中指定的端口号

通过上述步骤, 您就可以在 macOS 上启动一个本地的 Express 静态服务来托管静态资源文件了
