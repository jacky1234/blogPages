# 🔌 hdc 速查手册（HarmonyOS Device Connector）

hdc 是鸿蒙版的 adb。本文按能力域组织：不求罗列全部参数，而是让你知道 hdc 能干哪些大事、每个域最常用的命令长什么样。 所有命令均在真机（API 24，hdc 3.2.0c）上验证过；实战配方来自真实 GPU 渲染内存排查实验的踩坑沉淀。

# 🗺️ 能力域总览

# 能力域 关键命令 对应 adb
1 设备连接 list targets / tconn / tmode devices / connect
2 应用管理 install / bm / aa pm / am
3 文件传输 file send / file recv push / pull
4 Shell 与设备端脚本 shell "循环..." shell
5 日志 hilog logcat
6 系统服务转储 hidumper -s <SA> -a '...' dumpsys
7 性能与内存观测 hidumper --mem / --mem-jsheap / hiperf dumpsys meminfo
8 输入注入与 UI 自动化 uinput / uitest input tap/swipe
9 端口转发 fport / rport forward / reverse
10 截屏与布局 snapshot_display / uitest screenCap screencap
11 调试支持 jpid / shell -b / bugreport jdwp / bugreport

hdc tmode port close      # 关闭 TCP 端口

# 串口（UART）

# ★ 设备端循环：把循环放进一次 shell 调用

核心认知：host 每发起一次 hdc shell 都有秒级往返开销。host 端 for 循环 100 次 = 100 次 host↔device 往返（实测 ~9s/次），驱动/压测场景完全不可用。正确姿势是整段脚本一次下发，循环在设备端跑：

# 滑动注入 2 次，1.2s 间隔（$ 必须转义成 \$，防止被本机 shell 提前展开）
hdc shell "i=0; while [ \$i -lt 2 ]; do uinput -T -m 612 2100 612 600 200 >/dev/null 2>&1; i=\$((i+1)); sleep 1.2; done"
1
2

转义要点：

  • host 双引号内的 $i、$((...)) 都要写成 \$i、\$((...))
  • 复杂脚本别硬塞一行：hdc file send drive.sh /data/local/tmp/ → hdc shell "sh /data/local/tmp/drive.sh"
  • 拿 pid 再拼命令：hdc shell "pidof com.example.app"，或 hdc shell "ps -ef | grep xxx"

# 头尾
hdc shell hilog -a 100    # 头 100 行
hdc shell hilog -z 100    # 尾 100 行

# 落盘
hdc shell hilog -x > dump.log
hdc shell "hilog -T MyTag" | grep --line-buffered keyword

# 6. 系统服务转储：hidumper ★★ 最强的"透视镜"

hidumper 是 dumpsys 的等价物，但能力更强：不仅能转储系统服务，还能直接做内存/CPU/网络/故障分析。

hdc shell hidumper -ls                     # 列出所有系统服务（SA）
hdc shell hidumper -s                      # 转储全部服务
hdc shell hidumper -s <SA> -a '<参数>'     # 转储指定服务 + 参数（参数随服务而定）
hdc shell hidumper -s <SA> -a '-h'         # 很多服务支持 -h 查自己的参数！

# RenderService 三板斧（GPU/渲染内存排查，来自实战）

# 按 pid 的渲染内存记账：node/pixelmap/GPU 分项 + totalSize（强杀判据方）
hdc shell "hidumper -s RenderService -a 'dumpExistPidMem <pid>'"

# 各进程 GPU 内存 + RS 全局汇总；输出后半段 kmd-ctx 表 = 驱动级真·显存
hdc shell "hidumper -s RenderService -a 'dumpGpuMem'"

# 全部 surface 缓冲队列：总量 + BufferQueue 个数（泄漏 surface 会在这里堆积）
hdc shell "hidumper -s RenderService -a 'allSurfacesMem'"

# 7. 性能与内存观测

# 进程/系统内存（PSS 口径），支持 ashmem/dmabuf 明细
hdc shell hidumper --mem <pid>
hdc shell hidumper --mem <pid> --show-dmabuf
hdc shell hidumper --mem <pid> --show-ashmem
hdc shell hidumper --mem-smaps <pid> -v        # smaps 统计

# ★ ArkTS 堆分析（JS/Native 堆快照，可触发 GC、查泄漏对象）
hdc shell hidumper --mem-jsheap <pid> --gc          # 触发 GC
hdc shell hidumper --mem-jsheap <pid> --leakobj     # dump 泄漏对象列表
hdc shell hidumper --mem-jsheap <pid> --raw         # dump 原始堆

# CPU
hdc shell hidumper --cpuusage [pid]           # CPU 占用（按进程/分类）
hdc shell hidumper --cpufreq                  # 各核实时频率
hdc shell hidumper -p <pid>                   # 线程/smap/执行时间

# IPC 负载
hdc shell hidumper --ipc <pid> --start-stat
hdc shell hidumper --ipc <pid> --stat

# 性能剖析（perf 等价物）
hdc shell hiperf stat -p <pid> --duration 10
hdc shell hiperf record -p <pid> -o /data/local/tmp/perf.data
hdc shell hiperf report -i /data/local/tmp/perf.data

# 8. 输入注入与 UI 自动化：uinput / uitest ★

两套注入工具，性能差异巨大，选对工具是关键：

工具 通道 速度 适用
uitest uiInput 无障碍树 慢（负载下实测 ~8.6s/次） 语义操作、需要窗口感知
uinput -T 内核级 快（~0.8s/次） 高频驱动、压测复现

# uinput（内核级，快）

hdc shell uinput -T -c 328 2622                    # 点击 (328,2622)
hdc shell uinput -T -m 612 2100 612 600 500        # 滑动 (612,2100)→(612,600)，速度 500
#   -m x1 y1 x2 y2 [-k 保持时长ms] [平滑时长ms]
#   平滑时长默认 1000ms（最大 15000ms）；-k 保持最大 60000ms；最多支持三指同滑
hdc shell uinput -T -d 612 2100                   # 按下
hdc shell uinput -T -u 612 600                     # 抬起（自己组合长按）
hdc shell uinput -T -g 100 100 300 300 500 1000    # 拖拽（按下≥500ms）
# 其他通道：-K 键盘  -M 鼠标  -S 触控笔  -P 触控板  -k 指关节
hdc shell uinput -T -i 500                         # 事件间隔 500ms

# ⚠️ 滑动节奏踩坑（实战验证）

  • 滑动间隔 < 2s 会"橡皮筋"：页面只滑出 1/4 即回弹，切换不提交（150 次尝试仅 11 次生效）
  • 2s/次 ≈ 人类提交极限；客诉"29 次/min ≈ 2.07s/次"与此吻合
  • 高频驱动配方：uinput -T -m ... 500 + sleep 1.2（≈37/min，每次都提交）

# 踩坑清单（每条都交过学费）

  1. host 循环 = 灾难：for i in ...; do hdc shell ...; done 每次 ~9s 往返开销，循环必须放设备端（§4）
  2. uitest 慢：走无障碍树，负载下 ~8.6s/次；高频场景只配用来 dumpLayout 定位坐标
  3. 滑动 <2s 橡皮筋：滑出 1/4 即回弹、切换不提交；2s/次是人类提交极限
  4. PSS 看不到 RS 记账：GPU 渲染内存问题必须用 hidumper -s RenderService，PSS 只是 app 进程侧口径
  5. $ 转义：host 双引号内 \$i、\$((i+1))，否则被本机 shell 提前展开成空串
  6. pid 里有 \r：hdc shell 输出带 CR，拼接命令前先 tr -d '\r'

# 14. 自查命令的方法（授人以渔）
