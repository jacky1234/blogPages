# npm (Node Package Manager)

官方文档: npm (opens new window)
详细教程: npm 完整指南

# 核心特点

  • 官方工具: Node.js 的默认包管理器，随 Node.js 一起安装
  • 生态系统: JavaScript 社区最大的包管理生态系统
  • 版本管理: 通过 package.json 和 package-lock.json 管理依赖版本
  • 命令行工具: 提供完整的包安装、更新、卸载功能

# 常用命令

# 初始化项目
npm init
npm init -y

# 安装依赖
npm install <package>
npm install <package> --save-dev
npm install <package> -g

# 更新依赖
npm update
npm update <package>

# 卸载依赖
npm uninstall <package>

# 查看依赖
npm list
npm list --depth=0

# 运行脚本
npm run <script>
npm start
npm test

# 清理缓存
npm cache clean --force

# npx (Node Package Execute)

详细教程: npx 完整指南

# 核心特点

  • 无需安装: 直接运行 npm 包，无需全局安装
  • 版本指定: 可以运行特定版本的包
  • 临时使用: 运行完毕后自动清理
  • 脚本执行: 执行 node_modules/.bin 中的命令

# 使用场景

# 创建项目（无需全局安装）
npx create-react-app my-app
npx create-vite my-vue-app

# 运行特定版本
npx webpack@4.46.0 --version

# 执行本地二进制文件
npx eslint .
npx prettier --write .

# 临时测试工具
npx http-server
npx json-server --watch db.json

# Webpack

官方文档: Webpack (opens new window)

# 核心功能

  • 模块打包: 处理 JavaScript 模块（ES6、CommonJS、AMD）及其他资源
  • 代码分割: 将代码分割成多个 bundle，按需加载，减少初始加载时间
  • 热模块替换（HMR）: 开发过程中无需刷新页面即可替换、更新模块
  • Tree Shaking: 移除未使用的代码，减小打包体积
  • Loaders 和 Plugins: 使用 loaders 处理非 JavaScript 文件（如 CSS、图片），使用 plugins 扩展功能

# 基础配置

// webpack.config.js
const path = require('path');
const HtmlWebpackPlugin = require('html-webpack-plugin');

module.exports = {
  // 入口文件
  entry: './src/index.js',
  
  // 输出配置
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'bundle.[contenthash].js',
    clean: true
  },
  
  // Loaders 配置
  module: {
    rules: [
      {
        test: /\.js$/,
        exclude: /node_modules/,
        use: {
          loader: 'babel-loader',
          options: {
            presets: ['@babel/preset-env']
          }
        }
      },
      {
        test: /\.css$/,
        use: ['style-loader', 'css-loader']
      },
      {
        test: /\.(png|jpg|gif|svg)$/,
        type: 'asset/resource'
      }
    ]
  },
  
  // Plugins 配置
  plugins: [
    new HtmlWebpackPlugin({
      template: './src/index.html'
    })
  ],
  
  // 开发服务器配置
  devServer: {
    static: './dist',
    hot: true,
    port: 3000
  },
  
  // 优化配置
  optimization: {
    splitChunks: {
      chunks: 'all'
    }
  }
};

# Vite

官方文档: Vite (opens new window)

# 核心特点

  • 快速冷启动: 使用原生 ES 模块，无需打包即可启动
  • 即时热更新: 基于 ESM 的 HMR，更新速度极快
  • 按需编译: 只编译当前需要的模块
  • 多框架支持: 支持 Vue、React、Svelte 等
  • 开箱即用: 零配置启动，内置优化

# 基础配置

// vite.config.js
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import react from '@vitejs/plugin-react'

export default defineConfig({
  // 插件配置
  plugins: [vue(), react()],
  
  // 开发服务器配置
  server: {
    port: 3000,
    open: true,
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, '')
      }
    }
  },
  
  // 构建配置
  build: {
    outDir: 'dist',
    sourcemap: true,
    rollupOptions: {
      output: {
        manualChunks: {
          vendor: ['vue', 'vue-router']
        }
      }
    }
  },
  
  // 路径别名
  resolve: {
    alias: {
      '@': '/src'
    }
  }
})

# Gulp

官方文档: Gulp (opens new window)

# 核心特点

  • 任务型构建工具: 基于流（Stream）的任务运行器
  • 配置驱动: 通过 gulpfile.js 定义任务
  • 插件生态: 庞大的插件系统
  • 代码优于配置: 使用 JavaScript 编写任务

# 基础配置

// gulpfile.js
const gulp = require('gulp');
const sass = require('gulp-sass')(require('sass'));
const uglify = require('gulp-uglify');
const concat = require('gulp-concat');
const cleanCSS = require('gulp-clean-css');
const imagemin = require('gulp-imagemin');

// 编译 Sass
gulp.task('sass', function() {
  return gulp.src('src/scss/**/*.scss')
    .pipe(sass().on('error', sass.logError))
    .pipe(cleanCSS())
    .pipe(gulp.dest('dist/css'));
});

// 压缩 JavaScript
gulp.task('scripts', function() {
  return gulp.src('src/js/**/*.js')
    .pipe(concat('bundle.js'))
    .pipe(uglify())
    .pipe(gulp.dest('dist/js'));
});

// 优化图片
gulp.task('images', function() {
  return gulp.src('src/images/**/*')
    .pipe(imagemin())
    .pipe(gulp.dest('dist/images'));
});

// 监听文件变化
gulp.task('watch', function() {
  gulp.watch('src/scss/**/*.scss', gulp.series('sass'));
  gulp.watch('src/js/**/*.js', gulp.series('scripts'));
});

// 默认任务
gulp.task('default', gulp.series('sass', 'scripts', 'images'));

// 开发任务
gulp.task('dev', gulp.series('default', 'watch'));

# 实用脚本

#!/bin/bash
# 快速运行 TypeScript 文件
# 使用: ./runts.sh src/index.ts

if [ $# -eq 0 ]; then
  echo "Please provide a TypeScript file path as an argument."
  exit 1
fi

# 执行编译
tsc

# 将 src 替换为 dist，将 .ts 替换为 .js
file_path=$(echo $1 | sed 's/src/dist/; s/\.ts/\.js/g')

# 检查文件是否存在
if [ ! -f "$file_path" ]; then
  echo "File does not exist: $file_path"
  exit 1
fi

# 使用 Node.js 执行文件
node $file_path

# Monorepo 工具

# node-gyp

官方文档: node-gyp (opens new window)

# 什么是 node-gyp

node-gyp (Generate Your Projects) 是 Node.js 生态系统中不可或缺的一部分，它提供了一个平台，让 JavaScript 开发者能够轻松地集成 C 和 C++ 编写的代码。

# 为什么需要 node-gyp

Node.js 主要使用 JavaScript，一种解释型语言，但某些功能（如性能密集型任务或系统级操作）最好使用编译型语言如 C 或 C++ 来实现。node-gyp 就是连接这两个世界的桥梁，它让 Node.js 能够执行这些编译型语言编写的模块。

# 工作原理

当开发者创建一个需要 C/C++ 库的 Node.js 模块时，node-gyp 帮助配置和构建这些本地依赖。它使用 gyp（Generate Your Projects），一个 Google 开发的构建工具，用于生成项目文件，这些文件随后可被编译器如 gcc、clang 等用于构建最终的本地模块。
