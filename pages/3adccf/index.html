# klogg

klogg is an open source multi-platform GUI application to search through all kinds of text log files using regular expressions. It has started as fork of glogg project created by Nicolas Bonnefon, and has evolved into a separate project with a lot of new features and improvements.

非常好用的问题查找工具,更多内容可以点击 (opens new window)

  • mark
  • Highlights: 支持导入/导出
  • predefined filters: 支持导入/导出, 太方便了

button:

  • Enable regular expression logical combining: link (opens new window)
    • This button enables the special mode where you can write combinations of regular expressions, like this "exp1" or "exp2" and not "exp3". In this mode each expression has to be surrounded by ". Your expression then should be like this: ""startdate" : "[^"]"
    • For normal regex search it should be unselected. Then the pattern "startdate" : "[^"] works as expected.
  • use regex

正则生效的配置如上图, 一定要注意上面两个 button 模式

搜索中文无结果
  • 注意 Encoding 的设置。 (Encoding->xxx)
  • 正则场景下, 使用 (<中文>|xxx) 这样的正则表达式, 不要直接搜索中文

# amphetamine 防睡眠工具

Amphetamine (opens new window) 是一款免费的 macOS 防睡眠工具，可以防止 Mac 进入睡眠状态，适用于长时间下载、编译、渲染等场景。

主要功能：

  • 防睡眠模式：防止 Mac 进入睡眠状态，保持屏幕常亮
  • 定时设置：支持设置防睡眠时长，如 30分钟、1小时、2小时等
  • 触发条件：可以设置特定应用运行时自动启动防睡眠
  • 状态栏控制：通过状态栏图标快速开启/关闭防睡眠
  • 快捷键支持：支持自定义快捷键控制
  • 网络检测：可以检测网络活动，在网络传输时保持唤醒
  • 电池保护：在电池电量低时自动停止防睡眠

使用场景：

  • 长时间下载大文件
  • 代码编译和构建
  • 视频渲染和转码
  • 远程桌面连接
  • 系统备份和同步
  • 网络直播和会议

安装方式：

  • 从 Mac App Store 免费下载
  • 从官网下载 (opens new window)

使用技巧：

  • 在状态栏点击图标可以快速切换防睡眠状态
  • 右键点击状态栏图标可以设置定时和触发条件
  • 建议在电池模式下谨慎使用，避免电量耗尽
