nvm 使用指南

NVM (Node Version Manager) 是一个用于管理多个 Node.js 版本的工具，让你可以轻松在不同项目间切换 Node.js 版本。

# 什么是 nvm

NVM 允许你：

  • 🔄 安装多个 Node.js 版本
  • 🔀 在不同版本间快速切换
  • 📦 为每个版本管理独立的 npm 包
  • 🎯 为不同项目指定特定版本

# 安装 nvm

# Linux/macOS

# 安装最新版本
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# 或者使用 wget
wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# 自动切换版本

在 ~/.zshrc 或 ~/.bashrc 中添加：

# 进入目录时自动切换 Node.js 版本
autoload -U add-zsh-hook
load-nvmrc() {
  local node_version="$(nvm version)"
  local nvmrc_path="$(nvm_find_nvmrc)"

  if [ -n "$nvmrc_path" ]; then
    local nvmrc_node_version=$(nvm version "$(cat "${nvmrc_path}")")

    if [ "$nvmrc_node_version" = "N/A" ]; then
      nvm install
    elif [ "$nvmrc_node_version" != "$node_version" ]; then
      nvm use
    fi
  elif [ "$node_version" != "$(nvm version default)" ]; then
    echo "Reverting to nvm default version"
    nvm use default
  fi
}
add-zsh-hook chpwd load-nvmrc
load-nvmrc

# 完整命令参考

# 基础命令

命令 说明
nvm --version 显示 nvm 版本
nvm --help 显示帮助信息
nvm current 显示当前使用的版本

# 版本管理

命令 说明
nvm install <version> 安装指定版本
nvm install --lts 安装最新 LTS 版本
nvm install node 安装最新版本
nvm uninstall <version> 卸载指定版本
nvm use <version> 切换到指定版本
nvm use --lts 切换到 LTS 版本

# 版本查看

命令 说明
nvm ls 列出已安装版本
nvm ls-remote 列出远程可用版本
nvm ls-remote --lts 列出远程 LTS 版本
nvm ls-remote <version> 列出匹配的远程版本

# 别名管理

命令 说明
nvm alias 显示所有别名
nvm alias <name> <version> 创建别名
nvm unalias <name> 删除别名

# 执行命令

命令 说明
nvm exec <version> <command> 在指定版本执行命令
nvm run <version> <script> 使用指定版本运行脚本

# 包管理

命令 说明
nvm install-latest-npm 升级当前版本的 npm
nvm reinstall-packages <version> 重新安装全局包

# 缓存管理

命令 说明
nvm cache dir 显示缓存目录
nvm cache clear 清理缓存

# 实用示例

# 快速设置开发环境
nvm install --lts
nvm alias default lts/*
nvm use default

# 项目开发流程
cd my-project
nvm use                    # 使用项目指定的版本
npm install                # 安装依赖
npm start                  # 启动项目

# 版本比较
nvm exec 16.20.0 node --version
nvm exec 18.17.0 node --version

# 批量操作
nvm install 16.20.0 18.17.0 20.5.0
nvm use 18.17.0
nvm alias default 18.17.0
