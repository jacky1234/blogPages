Shell 常用命令速查手册

# 📖 文档说明

本文档系统性地整理了日常开发中最常用的 Shell 命令，涵盖系统管理、包管理、文件操作、文本处理、网络工具、压缩解压等多个方面。适合作为快速查询手册使用。

使用建议

  • 使用 Ctrl+F 快速搜索命令
  • 每个命令都包含常用选项和实战案例
  • 建议结合 man 命令查看详细文档
  • 相关专题文档：sed | awk | xargs | fd

# 1. 系统信息

# mac设备硬件信息

在 macOS 终端中，你可以使用以下命令来查看当前设备的硬件信息：

  1. 获取详细的硬件概览（最推荐）： system_profiler SPHardwareDataType
  2. 查看处理器核心数： sysctl -n hw.ncpu
  3. 查看内存大小（以字节为单位）： sysctl -n hw.memsize
  4. 查看机器型号标识符： sysctl -n hw.model
  5. 查看操作系统版本： sw_vers

# uname

显示系统信息

常用选项：

选项 说明
-s 显示操作系统名称
-n 显示主机名
-r 显示内核版本
-m 显示机器架构
-a 显示所有信息

示例：

# 查看架构
uname -m
# 输出：x86_64 或 arm64

# 查看所有系统信息
uname -a
# 输出：Darwin hostname 23.6.0 Darwin Kernel Version...

# top

实时显示系统进程和资源使用情况

基本用法：

top
1

输出信息：

  1. 系统信息：Load averages、CPU 使用率、内存使用、磁盘活动
  2. 进程列表：PID、USER、%CPU、%MEM、TIME、COMMAND

常用选项：

top -u username    # 显示特定用户的进程
top -s 2           # 每 2 秒更新一次
top -n 5           # 更新 5 次后退出
top -o cpu         # 按 CPU 使用率排序
top -i             # 隐藏空闲进程

# scutil (macOS)

macOS 系统配置工具，用于查看网络、DNS、代理等系统级配置

命令 说明
scutil --nwi 查看当前活跃的网络接口、IP、路由等
scutil --dns 查看所有 DNS 解析器配置（含搜索域）
scutil --proxy 查看系统代理配置（HTTP/HTTPS/SOCKS/PAC）
scutil --get HostName 查看主机名
scutil -r hostname 检测到目标主机的网络可达性
scutil 进入交互式 Shell，直接查询配置字典

# tmutil

macOS Time Machine 管理工具，先查备份状态，不将删除／关闭备份作为默认操作。

命令 用途
tmutil status 当前备份任务状态
tmutil listbackups 列出备份；权限要求按本机提示处理
tmutil listlocalsnapshots / 列出指定卷的本地快照

更多选项以本机 man tmutil 为准。

# launchctl (macOS)

macOS 底层服务管理工具. 参考 notify.sh

常用命令：

命令 说明
launchctl list 列出所有服务
launchctl load <plist> 加载服务

launchctl start <service> 启动服务
launchctl stop <service> 停止服务
launchctl enable <service> 启用服务

# 加载服务（系统级别）
sudo launchctl load /Library/LaunchDaemons/com.example.service.plist

# 启动/停止服务
launchctl start com.example.service
launchctl stop com.example.service

# 卸载服务
launchctl unload ~/Library/LaunchAgents/com.example.service.plist

# systemctl (Linux)

Linux 服务管理工具（systemd）

命令 说明

# stat

显示文件详细信息

常用选项：

选项 说明
-f FORMAT（macOS） 指定输出格式；GNU stat 的 -f 是文件系统信息
-L 跟随符号链接
-t FORMAT（macOS） 时间格式；GNU stat 的 -t 才是简洁输出
-x（macOS） 详细输出；GNU stat 默认已输出详细信息

示例：

# 查看文件详细信息
stat file.txt
stat -x file.txt  # macOS 需要下述易读格式时

# macOS stat -x 输出示例（节选）:

# Modify: 2025-01-19 11:30:00
# Change: 2025-01-19 11:30:00

# 只显示文件大小（macOS）
stat -f %z file.txt

# 只显示修改时间（macOS）
stat -f %Sm file.txt

# Linux 格式化输出
stat --format='%n %s bytes' file.txt
stat --format='%y' file.txt  # 修改时间

# lsof

lsof (list open files) 列出打开的文件和网络连接

常用选项：

选项 说明
-p <pid> 指定进程 ID，查看该进程打开的所有文件
-u <user> 显示特定用户打开的文件
-i 显示所有网络连接（包括 TCP/UDP）
-i :<port> 显示指定端口的连接
-iTCP 只显示 TCP 连接
-iUDP 只显示 UDP 连接
-sTCP:LISTEN 只显示处于 LISTEN 状态的 TCP 连接
-P 不将端口号转换为服务名（显示数字端口如 80 而非 http）
-n 不将 IP 地址转换为主机名（加快显示速度）
-c <name> 显示指定命令名的进程打开的文件
+D <dir> 递归显示目录下被打开的文件

实战示例：

# 查看指定端口占用情况
lsof -i :8080

# 查看指定进程的所有网络连接（推荐组合）
lsof -nP -a -p 35169 -i

# 查看所有 TCP 监听端口
lsof -nP -iTCP -sTCP:LISTEN

# 查看指定进程的 TCP 监听端口
lsof -nP -a -p 35169 -iTCP -sTCP:LISTEN

# 查看 MySQL 相关连接
lsof -i | grep mysql

# 查看进程打开的所有文件
lsof -p 1234

# 查看某个目录下被打开的文件
lsof +D /var/log

# bindkey

在 macOS 的终端（通常使用 Zsh 作为默认 Shell）中，bindkey 命令的作用是将键盘快捷键（Key Bindings）映射到特定的 Shell 命令或编辑操作上。

简单来说，如果你觉得某些操作（比如删掉一整行、跳到行首）默认快捷键不好用，或者你想给某个复杂指令设个“一键触发”，就用 bindkey。

  • bindkey "快捷键" 功能插件或指令: 基础用法
  • bindkey: 看到一张长长的表，左边是键位码，右边是它触发的功能
  • bindkey | grep "\^B": 查看当前这个窗口里 Ctrl-B 到底被谁“劫持”了
  • bindkey -r "^G": 解绑 "^G"

# 场景 A：快速删除光标前的单词（类似 Option + Backspace）

有时候你输错了一个长路径，想一下删掉一个单词，可以绑定 Ctrl + W：

# 将 Ctrl + W 绑定到 backward-kill-word（向后删除单词）
bindkey '^W' backward-kill-word
1
2

# 场景 B：一键输入常用命令（快捷键变身“宏”）

假设你经常需要输入 git status，但不想每次都打字，你可以利用 -s 参数绑定一个字符串：

# 将 Ctrl + G 绑定为执行 "git status" 并在末尾自动回车 (\n)
bindkey -s '^G' 'git status\n'
1
2

设置后，你在终端按下 Ctrl + G，它会自动帮你打出命令并运行。

# 11.1 词频统计

LeetCode: https://leetcode-cn.com/problems/word-frequency/ (opens new window)

输入（words.txt）：

the day is sunny the the
the sunny is is
1
2

解决方案：

cat words.txt | tr -s ' ' '\n' | sort | uniq -c | sort -r | awk '{print $2,$1}'
1

输出：

the 4
is 3
sunny 2
day 1
1
2
3
4

命令解析：

  1. tr -s ' ' '\n' - 空格转换为换行（分词）
  2. sort - 排序（相同词相邻）
  3. uniq -c - 统计重复次数
  4. sort -r - 按数量倒序
  5. awk '{print $2,$1}' - 调换位置

# 11.2 转置文件

name alice ryan

#!/bin/bash
