color

颜色值透明度的百分数对应十六进制表 (opens new window)

ARGB 依次代表透明度(alpha)、红色(red)、绿色(green)、蓝色(blue)。以颜色值 #FF66CC99 为例, 其中, FF 是透明度, 66 是红色值, CC 是绿色值, 99 是蓝色值

# alpha

  • 透明度分为 256 个等级, 即 0 - 256, 0 就是透明, 255 就是不透明, 透明度 0(透明) –> 255(不透明) 对应着 16 进制 00(透明) –> FF(不透明), 比如: 50% 透明度；50% 也就是 256 的一半即 128, 因为是从 0 开始算的, 所以是 127, 转换成 16 进制就是 7F
  • 透明度和 不透明度 是两个概念, 它们加起来是 1, 或者 100%.
  • ARGB 中的透明度 alpha, 表示的是不透明度

  • rgb(a)、hex、hsl(a)、hsv(a)颜色转换工具 (opens new window)
