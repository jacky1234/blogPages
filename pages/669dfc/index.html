# 什么是 npm

npm (opens new window) (Node Package Manager) 是 Node.js 的官方包管理器，提供了完整的包管理和项目依赖管理功能。

# 核心功能

  • 包管理: 安装、更新、卸载 npm 包
  • 依赖管理: 管理项目依赖和版本
  • 脚本运行: 运行项目脚本
  • 包发布: 发布自己的 npm 包
  • 安全审计: 检查安全漏洞

# 版本控制

# 语义化版本

npm 使用语义化版本控制 (opens new window)（Semantic Versioning），版本号格式为：MAJOR.MINOR.PATCH。 底层使用 node-semver (opens new window) 库。范围（range）描述的是一组满足条件的版本集合；执行 npm install 时会在该集合内选取满足范围的最高版本（有 lock 文件时以 lock 为准）。

Version range syntax examples (opens new window)

  • MAJOR（主版本号）: 不兼容的 API 变更
  • MINOR（次版本号）: 向后兼容的功能性新增
  • PATCH（修订号）: 向后兼容的问题修正

# 版本范围符号

{
  "dependencies": {
    // 精确版本
    "package1": "1.2.3",
    
    // 锁定主版本号（允许 1.x.x，不包括 2.0.0）
    "package2": "^1.2.3",  // 推荐使用
    
    // 锁定次版本号（允许 1.2.x，不包括 1.3.0）
    "package3": "~1.2.3",
    
    // 任意版本
    "package4": "*",
    "package5": "latest",
    
    // 版本范围
    "package6": ">=1.2.3 <2.0.0",
    "package7": "1.2.3 - 2.3.4",
    
    // 或关系
    "package8": "1.2.3 || 2.3.4",
    
    // Git 仓库
    "package9": "git+https://github.com/user/repo.git",
    
    // 本地路径
    "package10": "file:../local-package"
  }
}

# 版本符号详解

预发布版本（如 1.2.3-beta.1）默认不会被 ^1.2.3 选中，除非范围本身包含 -beta 或你显式安装带 tag 的版本。

解释以上规则： 当你运行 npm install 更新项目依赖时，npm 编译器绝对不会自作聪明地把一个处于测试阶段的“预发布版本”（如 beta、rc 版）自动下载到你的项目中，除非你主动在配置文件里提到了这个测试版。

# 依赖冲突

解决方案:

# 查看冲突详情
npm ls <package>

# 使用 npm overrides（npm 8.3.0+）
{
  "overrides": {
    "package-name": "1.0.0"
  }
}

# 使用 npm-force-resolutions
npm install --save-dev npm-force-resolutions

# 在 package.json 添加
{
  "resolutions": {
    "package-name": "1.0.0"
  },
  "scripts": {
    "preinstall": "npx npm-force-resolutions"
  }
}

# 2. 合理使用版本范围

  "dependencies": {
    // ✅ 推荐: 使用 ^ 允许小版本更新
    "react": "^18.2.0",
    
    // ⚠️ 谨慎: 精确版本，不会自动更新
    "lodash": "4.17.21",
    
    // ❌ 避免: 使用 * 或 latest
    "axios": "*",
    "moment": "latest"
  }

# 5. 使用脚本自动化

{
  "scripts": {
    // 开发流程
    "predev": "npm run clean",
    "dev": "vite",
    "postdev": "echo 'Dev server stopped'",
    
    // 构建流程
    "prebuild": "npm run lint && npm run test",
    "build": "tsc && vite build",
    "postbuild": "npm run size-check",
    
    // 发布流程
    "prepublishOnly": "npm run build && npm test",
    "version": "git add -A",
    "postversion": "git push && git push --tags"
  }
}
