python 包管理器 pip

pip 是 Python 的包管理器, 用于安装、升级和管理 Python 包。它是 Python 的官方包管理工具, 提供了便捷的方式来获取、安装和管理第三方库和工具.

# 三方包管理工具 uv

uv 是一个用 Rust 编写的超快 Python 包管理器，由 Astral 团队开发（也是 Ruff 的开发者）。它是 pip 和 virtualenv 的替代品，速度快 10-100 倍。

# 创建虚拟环境
uv venv
uv venv --python 3.11

# 安装包
uv pip install requests
uv pip install -r requirements.txt

# 同步依赖
uv pip sync requirements.txt

# 查看已安装包
uv pip list

# 生成 requirements.txt
uv pip freeze > requirements.txt

# 安装包

# 安装最新版本
pip install requests

# 安装指定版本
pip install requests==2.28.0

# 版本控制

# 版本符号说明

在通过 pip 安装包时，可以使用以下版本控制符号：

符号 说明 示例 含义
== 精确版本 requests==2.28.0 必须是 2.28.0 版本
>= 大于等于 requests>=2.28.0 2.28.0 或更高版本
<= 小于等于 requests<=2.28.0 2.28.0 或更低版本
> 大于 requests>2.28.0 高于 2.28.0 的版本
< 小于 requests<2.28.0 低于 2.28.0 的版本
!= 不等于 requests!=2.28.0 除了 2.28.0 的任何版本
~= 兼容版本 requests~=2.28.0 >= 2.28.0 且 < 2.29.0
, 组合条件 requests>=2.25.0,<3.0.0 2.25.0 到 3.0.0 之间

# 版本控制示例

# 安装特定版本
pip install 'requests==2.28.0'

# 安装版本范围
pip install 'numpy>=1.18.0,<=1.19.0'

# 兼容版本（推荐用于主版本控制）
pip install 'pyarrow~=13.0.0'  # >= 13.0.0 且 < 14.0.0

# 排除特定版本
pip install 'django!=3.0.0'

# 组合多个条件
pip install 'pandas>=1.0.0,<2.0.0,!=1.5.0'

# 配置 pip

# 配置文件位置

pip 配置文件的位置（按优先级排序）：

  1. 命令行参数 - 最高优先级
  2. 环境变量 - PIP_* 形式
  3. 用户配置文件:
    • Linux/macOS: ~/.config/pip/pip.conf 或 ~/.pip/pip.conf
    • Windows: %APPDATA%\pip\pip.ini
  4. 全局配置文件:
    • Linux/macOS: /etc/pip.conf
    • Windows: C:\ProgramData\pip\pip.ini

# 配置镜像源

# 最佳实践

  1. 使用虚拟环境 - 避免全局安装污染
  2. 固定版本 - 在 requirements.txt 中使用精确版本
  3. 定期更新 - 使用 pip list --outdated 检查过期包
  4. 使用国内镜像 - 提高下载速度
  5. 避免使用 sudo - 使用 --user 或虚拟环境
