Claude Code 使用指南

# Claude Code

Claude Code 是 Anthropic 的编程助手，终端入口为 claude。本页维护客户端使用与连接选择；代理配置集中在 LiteLLM，本地模型服务集中在 Ollama。

终端与对话内命令

运行位置 命令 用途
普通 shell claude 在当前仓库启动
普通 shell claude --help 核对已安装版本的参数
Claude Code 对话框 /help 查看交互命令
Claude Code 对话框 /status 核对连接和会话状态
Claude Code 对话框 /clear 清理当前对话上下文

客户端安装与账户接入以 Claude Code 官方文档 (opens new window) 为准。

模型连接选择

场景 配置维护位置 核对重点
官方服务 官方接入说明 (opens new window) 登录方式与所用模型
通过 LiteLLM 接入多种后端 LiteLLM：Claude Code 配置 Messages API、代理模型别名和鉴权
直接连接 Ollama Ollama：Claude Code 接入 Anthropic 兼容接口、工具调用和上下文

Claude Code 使用 Anthropic Messages 协议。OpenAI 兼容的 /v1/chat/completions 与它不是同一种接口，不能仅改端口就认为兼容。LiteLLM 的相应入口见 官方集成说明 (opens new window)；Ollama 的相应入口见 官方集成说明 (opens new window)。

排查顺序

先确认后端服务可连接，再核对客户端实际继承的 base URL、模型名及凭据。环境变量修改后要重新启动客户端。普通文本能回答，只能说明基础链路可用；还需要单独验证工具调用、流式响应与多轮上下文。完整检查集中在对应后端文章，避免多处维护不同的配置。

Claude Code 和 Codex 的进程、会话标识及交互命令不能互用，Codex 的 CLI / App 会话关联见 Codex 指南。
