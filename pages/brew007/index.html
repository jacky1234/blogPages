# Homebrew (brew) 参考手册

macOS（也支持 Linux）的包管理器，用于安装命令行工具和 GUI 应用。官方软件包搜索：Homebrew Formulae (opens new window)

# 安装与卸载

# 安装（官方脚本）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 卸载
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/uninstall.sh)"

安装后按提示将 brew 加入 PATH：

  • Apple Silicon（M 系列）：/opt/homebrew/bin
  • Intel：/usr/local/bin

# 常用命令速查

命令 说明
brew search <keyword> 搜索软件包
brew install <package> 安装软件包
brew uninstall <package> 卸载软件包
brew reinstall <package> 强制重新安装
brew update 更新 Homebrew 本身和包索引（公式库）
brew upgrade 升级所有已安装软件到最新版
brew upgrade <package> 升级指定软件
brew list 列出已安装的所有命令行工具
brew list --versions 列出已安装包及版本号
brew info <package> 查看软件详细信息、依赖、安装路径
brew deps <package> 查看依赖关系
brew deps --tree <package> 树形显示依赖
brew uses <package> 查看哪些包依赖它
brew outdated 查看可升级的包
brew cleanup 清理旧版本和下载缓存
brew cleanup -n 预览将清理什么（不执行）
brew cleanup --prune=all 清理所有缓存
brew doctor 诊断系统问题
brew config 查看 brew 配置信息
brew pin <package> 锁定版本（upgrade 时跳过）
brew unpin <package> 解除锁定
brew autoremove 卸载不再被依赖的孤立包
brew missing 检查依赖是否完整

brew update vs brew upgrade：update 只更新本地包索引（相当于 apt update），不升级软件；upgrade 才实际升级已安装的包。日常操作先 update 再 upgrade。

# Cask：安装 GUI 应用

brew cask 用于安装带图形界面的应用（Chrome、VS Code、Docker 等），命令与普通 brew 一致，加 --cask：

# 搜索和安装
brew search --cask <keyword>
brew install --cask google-chrome
brew install --cask visual-studio-code docker iterm2

# 查看和管理
brew list --cask           # 列出已安装的 GUI 应用
brew info --cask google-chrome
brew uninstall --cask google-chrome
brew upgrade --cask        # 升级所有 GUI 应用

# Services：管理后台服务

用于管理 MySQL、Redis、Nginx 等需要后台运行的服务：

brew services list                    # 查看所有服务状态
brew services start <name>            # 启动服务并设为开机自启
brew services stop <name>             # 停止服务并取消开机自启
brew services restart <name>          # 重启
brew services run <name>              # 仅启动，不设开机自启
brew services cleanup                 # 清理未使用的服务

# 多版本切换

# 安装指定版本
brew install python@3.9 python@3.11

# 切换版本：先 unlink 当前版本，再 link 目标版本
brew unlink python && brew link python@3.11 --overwrite --force

# 查看当前链接版本
brew list --versions python

# 国内镜像加速

默认从 GitHub 拉取，国内网络慢时可替换为中科大或清华镜像：

# 中科大镜像
export HOMEBREW_API_DOMAIN="https://mirrors.ustc.edu.cn/homebrew-bottles/api"
export HOMEBREW_BOTTLE_DOMAIN="https://mirrors.ustc.edu.cn/homebrew-bottles"
export HOMEBREW_BREW_GIT_REMOTE="https://mirrors.ustc.edu.cn/brew.git"
export HOMEBREW_CORE_GIT_REMOTE="https://mirrors.ustc.edu.cn/homebrew-core.git"

# 写入 ~/.zshrc 持久生效
echo 'export HOMEBREW_API_DOMAIN="https://mirrors.ustc.edu.cn/homebrew-bottles/api"' >> ~/.zshrc
echo 'export HOMEBREW_BOTTLE_DOMAIN="https://mirrors.ustc.edu.cn/homebrew-bottles"' >> ~/.zshrc

# 实用技巧

# 查看安装根目录和缓存目录
brew --prefix
brew --prefix <package>    # 查看指定包的安装路径
brew --cache                # 查看下载缓存目录

# 安装时跳过自动 update
HOMEBREW_NO_AUTO_UPDATE=1 brew install <package>

# 下载包但不安装（查看安装脚本）
brew fetch <package>

# 查看某个命令由哪个包提供
brew which <command>

# 定期维护
brew update && brew upgrade && brew cleanup

# 常见问题排查

问题 原因 解决方案
brew command not found 未将 brew 加入 PATH Apple Silicon 加 /opt/homebrew/bin，Intel 加 /usr/local/bin 到 PATH
Permission denied 目录权限问题 sudo chown -R $(whoami) $(brew --prefix)/*
安装慢/卡住 网络问题 换国内镜像，或设 ALL_PROXY 走代理
brew doctor 有 warning 路径或旧版本残留 按提示逐条修复，不影响使用可忽略
升级后旧版本还在 未清理 brew cleanup 清理旧版本
依赖冲突 多版本共存 brew unlink + brew link 切换，或 brew reinstall
