# 1. 什么是求导

求导（微分）用于求函数在某点的瞬时变化率。

# 1.1 几何意义

导数等于函数图像在该点的切线斜率。

# 1.2 物理意义

位移对时间的导数是速度；速度对时间的导数是加速度。
